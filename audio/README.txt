Backing loop slot for the Tilt Bass homepage.

Drop the file here as:  backing-loop.mp3
- Content: the Orbital Overdrive groove with NO bass, 8 or 16 bars, starting exactly on the downbeat.
- Format: MP3 (44.1 or 48 kHz, stereo, 192-320 kbps). Export with LAME so the gapless header is kept.
- Then set LOOP.bpm and LOOP.bars in ../index.html (e.g. bpm: 128, bars: 8) so the loop length is exact
  and any MP3 padding at the end is skipped (no gap or click at the loop point).
- If this file is missing, the page runs as a solo bass with no errors.
